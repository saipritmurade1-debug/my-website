QUESTION / CONCEPT

What is the difference between Safety and Liveness properties in a distributed consensus algorithm?

Click anywhere to flip & see answer

VERIFIED ANSWER

Safety: "Nothing bad happens" (e.g., two distinct nodes will never decide on different values at the same slot).

Liveness: "Something good eventually happens" (e.g., the system guarantees it will eventually reach a decision).
